## 2. 基础、牌山与动作

| 条目 | 建议约定 |
| --- | --- |
| 人数与用牌 | 四人；34 种、每种 4 枚，共 136 枚，万／筒／索各一枚赤五替换普通五 |

| 座位与起家 | 沿用自动入座；首席起家，之后庄家按东→南→西→北轮转。桌位固定，自风按当局庄家计算；以后加入掷骰表现时另行讨论，不暗改起家 |
| 配牌 | 每人 13 枚，庄家首摸形成 14 枚；正常牌山 70 枚可供摸取，首摸后剩 69 枚 |
| 王牌 | 保持 14 枚，包含 4 枚岭上牌及最多 5 对表／里指示牌。每次岭上补牌同时将可摸牌山末尾一枚转入王牌，禁止凭空补牌 |

| 吃与碰 | 吃只取上家舍牌，碰可取任一家舍牌；用赤／非赤牌存在多个组合时保留具体选择，不能悄悄换用另一枚牌 |
| 响应优先级 | 荣和＞碰／大明杠＞吃。先收齐该次响应再裁决，不以网络先到者获胜；无人拥有合法响应，或收齐响应后无人选择合法声明时，推进下一摸。允许有合法动作的玩家明确跳过 |

| 非法操作 | 不造成状态变更，不自动罚分。自动化核心不模拟实体牌桌的误摸、错报点、诈和罚则；每次结算有唯一结果标识，重放不重复支付 |

游戏接入时的响应倒计时和按钮表现不在本轮代码范围；离线核心接受明确的各家响应，不依赖帧率、真实时钟或客户端动画。

## 3. 和牌、听牌与振听

| 条目 | 建议约定 |
| --- | --- |
| 标准形 | 4 面子＋1 雀头；每个已声明杠占一个面子，实际总牌数为 14＋杠数 |
| 七对子 | 门清、7 种不同对子；4 枚同牌不能当两个对子，声明暗杠后也不能判七对子 |
| 国士无双 | 门清，13 种幺九牌各至少一枚，且其中一种成对子；不能包含任何已声明杠 |
| 结构与和牌合法性 | “结构完成”“有役”“未振听且当前可荣和”分别计算；结构完成不代表可以和牌 |
| 多种拆解 | 枚举全部面子分解及和牌张所完成的面子／雀头，分别判役、符和支付，取合法且实际支付最高者；不能只取第一种拆解或只比较番数 |
| 流局听牌 | 允许无役与振听的形式听牌；不以牌山或他家是否仍有等待牌作为条件。禁止假想第 5 枚：本人手牌连同副露已使用某牌 4 枚，该牌不能作为有效等待 |
| 舍牌振听 | 当前结构等待中只要有任一牌种曾被本人舍弃，全部荣和等待均受限；被他家鸣走的本人舍牌也计入，自己加杠亮出的牌不算舍牌 |
| 同巡振听 | 未立直时放过结构可和的他家牌／可抢杠牌，即使当时无役，也进入临时振听。建议到本人下一次摸牌解除；若先吃碰，则到该次副露弃牌后解除，他人鸣牌不解除 |
| 立直振听 | 立直后放过和牌机会，本局内不能再荣和；舍牌振听也不会因手牌被锁定而消失 |
| 振听与自摸 | 振听限制荣和及抢杠，不限制合法自摸；允许振听立直 |

同巡振听解除时点属于明确的项目选择，不能直接混用“取到牌”“打出牌”或“每一桌面巡结束”等不同实现。

## 4. 立直与杠

| 条目 | 建议约定 |
| --- | --- |
| 立直条件 | 门清、弃牌后结构听牌、持点至少 1,000，宣言时可摸牌山至少剩 4 枚；暗杠不破门清 |
| 宣言成立 | 立直和宣言弃牌作为一个待裁决动作。该弃牌的荣和／三家和若终结本局，立直不成立、不收 1,000；否则成立并向供托支付 1,000。宣言牌被吃碰不取消立直 |
| 立直后操作 | 除合法自摸／荣和及允许的暗杠外，只能摸切；不能吃碰、明杠或加杠 |
| 双立直 | 本人第一次弃牌宣言，且之前没有任何吃、碰或杠；取代普通立直，不重复加番 |
| 一发 | 立直成立后到本人下一次弃牌前的和牌机会；任意吃、碰或已成立的杠中断。加杠被抢未成立时，中断发生在抢杠窗口之后；连续杠须逐次处理 |
| 暗杠／加杠 | 只能在本人摸牌后声明；大明杠在他家舍牌响应阶段声明。全桌最多 4 次已成立杠，岭上与可摸牌不足时不可开杠 |
| 立直后暗杠 | 建议采用严格版本：只杠新摸来的第四枚；等待牌集合不变，所有和牌拆解都必须将原三枚用作该暗刻，替换为暗杠后其余结构及和牌张归属不变。不能只比较等待集合就放行 |
| 抢杠 | 允许抢加杠；暗杠仅允许国士无双抢杠。大明杠所取牌在原舍牌荣和窗口处理，不另造一个普通抢杠机会；振听仍适用 |
| 杠宝牌 | 建议所有已成立的杠立即翻新指示牌，再摸岭上。被抢的杠不成立、不翻牌、不补岭上、不转移牌山末枚；立直和牌可看对应杠里宝牌 |
| 岭上与四杠 | 岭上自摸计岭上开花及自摸符；第四杠若由多人完成，先允许岭上自摸及其后弃牌的荣和，均无人和才四杠散了；四杠均归同一人则继续，禁止第五杠 |

严格暗杠、国士抢暗杠、杠宝牌即时翻开是本稿建议值，并非声称天凤、M 联赛、WRC 全部如此。

## 5. 役种与番符

“门清限定”包括可有合法暗杠；“食下”表示副露后少一番。一般役与宝牌只在没有真正役满时累计；役满牌不再叠加普通役和宝牌。

| --- | --- | --- |
| 1 | 立直、一发、门前清自摸和、平和、一杯口 | 门清限定；一发须立直成立 |
| 1 | 断幺九、役牌、岭上开花、抢杠、海底捞月、河底捞鱼 | 断幺可副露；白／发／中、自风、场风各自计役牌，连风刻子 2 番 |
| 2 | 双立直、七对子 | 门清限定 |
| 2 | 对对和、三暗刻、三杠子、三色同刻、混老头、小三元 | 可副露；荣和完成的刻子不计暗刻；小三元另计两组役牌 |
| 2→1 | 三色同顺、一气通贯、混全带幺九 | 食下；混全须含字牌且至少一个顺子 |
| 3 | 两杯口 | 门清限定，取代一杯口，不能同时按七对子计算 |
| 3→2 | 混一色、纯全带幺九 | 食下；纯全无字且至少一个顺子 |
| 6→5 | 清一色 | 食下；取代混一色 |
| 役满 | 天和、地和、国士无双、四暗刻、九莲宝灯 | 门清限定；天和为庄家初始 14 枚，地和为子家未受鸣杠打断的首摸；九莲须同花色 1112345678999 加任意一枚 |
| 役满 | 大三元、小四喜、大四喜、字一色、清老头、绿一色、四杠子 | 可副露；绿一色可不含发，仅限 23468 索及发 |
| 双倍役满（待确认 C） | 国士十三面、四暗刻单骑、纯正九莲、大四喜 | 前三者依和牌前的准确牌形／和牌张判断；取代对应单倍役满，不重复计算 |

不采用人和、八连庄、三连刻、一色三顺、大车轮、十三不靠等地方役。流局满贯作为第 7 节的特殊结算处理，不用于使普通和牌达到一番起和。

关键判定定义：

- 门前清自摸要求未吃碰明杠并以本人摸牌完成；断幺要求全手及副露均无幺九。役牌要求相关字牌刻子／杠子，只有一对字牌不构成役牌。
- 平和要求门清四顺子、非役牌雀头且和牌张以两面完成顺子；有其他两面解释不代表当前选定的边张／嵌张解释也能判平和。
- 一杯口为两个同花色同起点顺子；两杯口为四个顺子组成两组这种配对。两杯口取代一杯口，不能把另一个七对子解释的役叠到同一标准形解释。
- 对对和为四个刻子／杠子。三暗刻为至少三个暗刻／暗杠；三杠子为三个已声明杠。三色同刻为三花色同数字刻子／杠子；三色同顺为三花色同数字顺子。一气通贯须同花色的 123、456、789 三个实际顺子，不仅是手中出现过 1～9。
- 混全要求每个面子与雀头都含幺九，且至少一组顺子、至少一种字牌；纯全要求每组含数牌 1 或 9、无字牌且至少一组顺子；混老头全手只有幺九。小三元为两组三元刻子／杠子加另一种三元雀头。
- 混一色只含一种数牌花色及字牌，两者均有；清一色只有一种数牌花色。清一色不再叠混一色，纯全不再叠混全，双立直不再叠立直。
- 四暗刻为四个暗刻／暗杠；若荣和张补成刻子，该刻不是暗刻，不能判四暗刻。因此荣和四暗刻只能补雀头；自摸可以补刻子或雀头。
- 大三元为三组三元刻子／杠子；小四喜为三组风牌刻子／杠子加第四种风牌雀头；大四喜为四组风牌刻子／杠子。四杠子须四个已声明杠加雀头。字一色全为字牌，清老头全为数牌 1／9；绿一色仅使用 23468 索及发。
- 九莲除第 5 节牌形外，要求无已声明杠；即使暗杠不破门清也不能判九莲。国士十三面以和牌前 13 种幺九各一枚为准；纯正九莲以和牌前恰为 1112345678999 为准；四暗刻单骑以和牌前四个暗刻／暗杠加单张待雀头为准。天和也按服务器保留的首摸前手牌和真实首摸张判断，不凭完成牌形自动认定特殊双倍。
- 天和只在庄家初始配牌与首摸完成时判定；地和为子家首个正常自摸且之前无人吃碰杠。海底只判最后一枚普通摸牌，岭上不复合海底；河底按第 2 节末次弃牌判断，抢杠与岭上须使用各自真实牌源事件。

基本符规则：

- 标准形副底 20；门清荣和加 10，自摸加 2。平和自摸固定 20、平和荣和 30；副露无符荣和最低 30。七对子固定 25，不再加符或进位。
- 明刻中张／幺九 2／4，暗刻 4／8，明杠 8／16，暗杠 16／32。荣和张补成刻子时，该刻按明刻计算符与暗刻役，但整手未因此变成副露手。
- 三元、自风或场风雀头加 2；连风雀头建议 4。边张、嵌张或单骑加 2；一次和牌的等待符只取一个对应解释。
- 除七对子外，符数向上取整至十位；暗杠不取消门清荣和的 10 符。

## 6. 支付、役满责任与守恒

| 条目 | 建议约定 |
| --- | --- |
| 满贯以下 | 1～4 番基本点 `符 × 2^(番+2)`，至多 2,000；4 番 30 符／3 番 60 符按基本点 1,920 计算，不切上 |
| 上限 | 5 番满贯 2,000、6～7 番跳满 3,000、8～10 番倍满 4,000、11～12 番三倍满 6,000 基本点；累计 13 番及以上按 8,000 封顶，不因达到 26 番再翻倍 |
| 真役满 | 每单位 8,000 基本点，可复合；是否采用第 5 节特殊双倍按 C 确认。累计役满不与真役满叠加 |
| 荣和 | 子家基本点×4，庄家×6；放铳者支付，各支付项向上取整到百点 |
| 自摸 | 子家和牌：庄家付基本点×2，另两家各付基本点；庄家和牌：三家各付基本点×2，每人独立向上取整到百点 |
| 本场 | 每本场荣和另收 300，自摸每家另收 100。双响建议每位赢家分别收本场；供托只发一次 |
| 包牌范围 | 建议只对大三元、大四喜设责任支付，不含四杠子。由某人提供最后一组明刻／大明杠，使相应三元／四风全部成为已公开组时，记录该提供者；自己摸成暗刻／暗杠不产生包牌 |
| 包牌结算 | 仅相应役满组件由责任者承担：自摸全付，荣和他家则责任者与放铳者各半，责任者自己放铳则全付；复合中其他组件照常支付。存在包牌时本场：自摸由责任者全付，荣和由放铳者付 |
| 账本 | 四人点数＋供托守恒；总额初始 100,000。立直仅把 1,000 从玩家转至供托，不销毁点数；每个结算至多应用一次 |

核心应输出每个役／符来源、采用的拆解、基本点、每家支付、供托与本场明细，供测试和以后界面解释。

| 流局满贯 | 建议采用：本人牌河非空且全为幺九、没有本人舍牌被鸣走，本人未吃碰明杠（暗杠允许）。按满贯自摸作为和牌结算，替代听牌罚符；多人达成时分别独立结算且互付，供托按当局庄→南→西→北顺序首个达成者取得；达成者有庄则连庄且本场＋1，仅子家达成则轮庄且本场清零，不因名字含“流局”而进入流局本场分支 |
| 常规连庄 | 庄家和牌（含双响）、庄家荒牌听牌或途中流局时连庄；其余轮庄。庄家和牌、荒牌或途中流局本场＋1，子家和牌本场清零；流局满贯按上一条作为和牌处理 |
| 赛制边界 | B 建议不延长、不提前止；到计划末局仍先执行连庄条件，直到可轮庄才结束整场。低于 0 点在一次完整结算后结束，不截断双响支付 |
| 排名 | 按原始最终点数，同点按起家时东南西北顺序；结束时剩余供托交第一名后再固定结果。不计算返还点、顺位马点或外部奖励 |

流局满贯的资格、结算性质、多人支付和连庄在不同规则中都有差异；本稿已经明确建议值，不能把它当作无需确认的通用规则。

## 8. 准确性与实现顺序

规则表确认后，按以下顺序做独立代码；每批通过再进行下一批，不先接入 Minecraft。规则核心的测试应能脱离游戏进程直接运行，当前游戏测试不能代替这套验证：

1. 牌与副露的合法输入、标准形／七对子／国士、全部分解与结构听牌；拒绝重复物理 ID、超过四枚同牌、错误总数和跨花色顺子。
2. 和牌上下文、全部普通役与役满、番符、最高得点拆解及可解释支付；把选定规则写成不可变的带版本预设。
3. 振听、立直／一发、鸣牌响应与杠的状态机；输入合法动作集合和响应结果，检查牌守恒及旧动作不重放。
4. 多人和牌、流局、包牌、供托／本场与东风／半庄轮转；检查点数守恒、幂等结算及末局边界。
5. 对照独立预期样例与固定种子整局模拟；另写与实现思路不同的结构判定交叉检查。公开规范有差异的地方以本预设为准，不把另一个预设的程序输出直接当真值。

必须预先写定预期的样例包括：

- 同牌四枚不能算两对；字牌不能顺子；各花色 9 与下一花色 1 不相连；暗杠破坏七对子／国士资格但不破门清。
- `1122334455667m` 自摸 `7m`：比较七对子与标准形；在无其他事件役、无宝牌时，清一色＋两杯口＋平和＋门清自摸可达 11 番，不能被较早找到的七对子解释遮蔽。
- 门清荣和补刻子的符与三暗刻判定、平和两面与边张的差别、连风雀头、七对子 25 符、最高番数不一定最高点数。
- 不切上时子家 4 番 30 符荣和 7,700、庄家 11,600；子家 1 番 30 符荣和 1,000，自摸支付为子家 300、庄家 500；七对子 2 番 25 符荣和子家 1,600、庄家 2,400。
- 无役但有多枚宝牌不能和；振听覆盖全部等待；鸣走的历史舍牌、无役见逃与抢杠见逃都不能漏判。
- 立直后等待集合相同但面子拆解变化的暗杠，按严格版本拒绝；被抢杠不能先翻新宝牌或消耗岭上。
- 第四杠后岭上／荣和优先、三家同时响应、立直宣言牌荣和、末次弃牌荣和优先于荒牌，及多个流局满贯的零和支付。
- 双响和包牌的本场／供托只按选定政策支付；包括供托的总点数始终为 100,000；重复结算与过期响应均不改变结果。

本轮不引入外部规则库依赖，不修改当前 v0.0.3 摸打与暂停交互。今后接入真实计分时，主动终止、跨重启保存及响应计时对账本的影响须单独确定，不能把当前无计分原型的清理逻辑直接套用。
