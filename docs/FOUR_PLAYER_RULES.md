## 3. 和牌、听牌与振听

| 条目 | 基线、通用定义与核实状态 |
| --- | --- |
| 标准形 | 4 面子＋1 雀头；每个已声明杠占一个面子，实际总牌数为 14＋杠数 |
| 七对子 | 门清、7 种不同对子；4 枚同牌不能当两个对子，声明暗杠后也不能判七对子 |
| 国士无双 | 门清，13 种幺九牌各至少一枚，且其中一种成对子；不能包含任何已声明杠 |
| 结构与和牌合法性 | “结构完成”“有役”“未振听且当前可荣和”分别计算；结构完成不代表可以和牌 |
| 多种拆解 | 枚举全部面子分解及和牌张所完成的面子／雀头，分别判役、符和支付，取合法且实际支付最高者；不能只取第一种拆解或只比较番数 |
| 真实可和的结构等待 | 首批 API 只返回加入一枚后可完成合法牌形、且本人暗手连同已声明面子尚未占用该牌全部 4 枚的牌种；忽略他家暗手和牌山库存，不判役或振听。这是结构等待，不是完整流局听牌裁决 |
| 流局形式听牌 | 官方认可形式听牌，并排除本人持有 4 枚时的单骑空听；无役、振听与外部牌已见尽不能直接等同不听。涉及已声明面子、其他第五枚等待的完整边界待核实，尚不实现；以后单设形式听牌 API，不把它混入首批真实可和的结构等待 |
| 舍牌振听 | 当前结构等待中只要有任一牌种曾被本人舍弃，全部荣和等待均受限；被他家鸣走的本人舍牌也计入，自己加杠亮出的牌不算舍牌。用户直接确认无役一侧的结构完成牌也计入 |
| 同巡振听 | 官方规定见逃和牌张（含抢杠）后至本人下一次摸牌不能荣和，FAQ id44 明确在该次摸牌解除；不得在吃碰后的弃牌自行解除。用户直接确认放过他家普通舍出的无役结构完成牌也触发；现已自动记录普通舍牌分支。暗杠非国士完成牌见逃仍待核实，不自动裁决 |
| 立直振听 | 已成立立直后放过结构完成牌，本局内不能再荣和；舍牌振听也不会因手牌被锁定而消失。普通舍牌按全部结构等待触发，来源为用户直接确认，不以计分或当前可荣和性筛选 |
| 振听与自摸 | 振听限制荣和及抢杠，不限制合法自摸；允许振听立直 |

同巡振听解除时点按雀魂官方说明，不是项目另选的策略；取得吃碰牌与自己摸牌是不同事件。

例如 `123m 456p 789s EE WW`（E＝东、W＝西），设东为役牌、西非役牌且无其他事件役：荣和东有役，荣和西无役。曾舍弃西，东、西均不能荣和；未立直时放过他家舍出的西，至本人下次摸牌前也不能荣和东。已成立立直后放过结构完成牌则本局持续振听；立直本身赋予役，不改变按全部结构等待触发的原则。这一无役边界由用户于 2026-10-16 直接确认。

本批 `FuritenAnalyzer` 以全部结构等待计算舍牌振听。`FuritenTracker.afterDiscardWithoutRon(waitingHand, discardedTileId, history, establishedRiichi)` 使用响应前、吃碰前的 13 张结构手牌，自动记录未荣和他家普通舍牌后的同巡／立直振听；不以 `HandScorer` 非空或 `WinEvaluator.allowed()` 为前提，非结构完成牌不改变历史。该接口不处理抢杠，不建立完整对局、行动者或响应窗口。`WinEvaluator` 自摸不受振听限制，荣和／抢杠则检查三类原因；本人舍牌仍由 `afterDiscard()` 记录。`afterDraw()` 按一般“本人下一次摸牌”处理；岭上没有另找到独立解除专条，不声称另有专条证明。具体契约见 [FURITEN.md](FURITEN.md)。

关键判定定义：

- 门前清自摸要求未吃碰明杠并以本人摸牌完成；断幺要求全手及副露均无幺九。役牌要求相关字牌刻子／杠子，只有一对字牌不构成役牌。
- 平和要求门清四顺子、非役牌雀头且和牌张以两面完成顺子；有其他两面解释不代表当前选定的边张／嵌张解释也能判平和。
- 一杯口为两个同花色同起点顺子；两杯口为四个顺子组成两组这种配对。两杯口取代一杯口，不能把另一个七对子解释的役叠到同一标准形解释。
- 对对和为四个刻子／杠子。三暗刻为至少三个暗刻／暗杠；三杠子为三个已声明杠。三色同刻为三花色同数字刻子／杠子；三色同顺为三花色同数字顺子。一气通贯须同花色的 123、456、789 三个实际顺子，不仅是手中出现过 1～9。
- 混全要求每个面子与雀头都含幺九，且至少一组顺子、至少一种字牌；纯全要求每组含数牌 1 或 9、无字牌且至少一组顺子；混老头全手只有幺九。小三元为两组三元刻子／杠子加另一种三元雀头。
- 混一色只含一种数牌花色及字牌，两者均有；清一色只有一种数牌花色。清一色不再叠混一色，纯全不再叠混全，双立直不再叠立直。
- 四暗刻为四个暗刻／暗杠；若荣和张补成刻子，该刻不是暗刻，不能判四暗刻。因此荣和四暗刻只能补雀头；自摸可以补刻子或雀头。
- 大三元为三组三元刻子／杠子；小四喜为三组风牌刻子／杠子加第四种风牌雀头；大四喜为四组风牌刻子／杠子。四杠子须四个已声明杠加雀头。字一色全为字牌，清老头全为数牌 1／9；绿一色仅使用 23468 索及发。
