**A组建议：保留区与操作边界。** 官方公开说明给出了“8枚岭上”，未给出完整的三麻牌墙索引与所有补牌组合示例。本稿建议：

1. 保留14枚不可普通摸取区；配牌39枚后活牌55枚，庄家首摸后54枚。每次已成立杠／拔北从统一8次补牌序列取一枚，同时将活牌末尾一枚划入保留区，活牌数减1。不能因为“8补牌＋5对指示”就把初始保留区擅自改成18枚。
2. 8次补牌与最多5对指示牌是**不同时间可用的位置**，不能预先划成两块互不相交且都不属于活牌的18枚。可用逻辑示例：108牌序末8枚作为补牌顺序，其前依次为5对指示位置；后几对初期可以位于活牌尾，只有足够杠／补牌将尾部移入保留区后才可翻开。实现前枚举所有合法杠／拔北交错，证明绝不翻到已摸走或可普通摸走的牌；逻辑洗牌次序不声称复制雀魂客户端的物理砌墙。
3. 杠与拔北共享8次补牌容量，北最多4枚、杠最多4次；无活牌或无补牌容量时不提供动作。一次只拔一枚，先处理抢北，再补牌；补到北可继续逐枚拔。
4. 只有本人摸牌操作阶段可拔北；未立直可选择任一自持北，碰后须先弃牌，不能在无摸牌的碰后阶段拔北。已成立立直后只可拔刚摸到的北，不能拔旧手牌中的北改变等待。
5. 立直须门清听牌、持点至少1,000，宣言后活牌至少剩3枚；这是对官方“仍有本人摸番”的三人门槛具体化，不能沿用四麻4枚阈值。拔北与合法暗杠不破门清。

以上是待用户确认的实施合同，不把未找到的官方精确牌墙布局、立直后三麻拔北限制冒称已核实判例。

**C组中的抢北时序建议：**

- 拔北宣言先进入独立响应窗；被抢则本次拔北不成立，不补牌、不翻新指示、不增加宣言者拔北数；只有被抢的那一枚北移为共享和牌张，先前已成立拔北不撤销。
- 只有无人荣和、正式成立的拔北才打断此前有效一发及首巡资格。因此被抢北的和牌保留宣言前仍有效的一发，不能直接从四麻“被抢杠”推定已获用户确认，现请单独裁定。
- 普通舍牌／加杠的结构完成牌继续按全部结构等待记录见逃；暗杠只对国士。新增抢北按所有结构完成北记录同巡／立直振听，即使该北当时无役；不得把“拔北不是舍牌”错误扩展成“放过抢北不振听”。
- 本人下一次真实摸牌解除同巡振听，包括普通、岭上和拔北补牌；碰后弃牌不解除。已立直见逃本局持续。
- 拔北不增加杠数、不翻新杠宝。此前明／加杠尚有延后指示时，拟仍在弃牌荣和计分前或下一次杠宣言前翻，不因随后拔北先翻；拔北补牌自摸仍不取得该次尚未翻开的延后宝。
- 在多人第四杠待弃牌阶段，拟先完成该次岭上自摸／弃牌荣和门槛，不插入新的拔北或杠来规避流局。

这几条均为新事件精确时序的**拟定裁定**，不是找到新的雀魂逐例官方说明。

## 4. 牌形、役、符与可成立性

标准形四面子一雀头、七种不同对子、国士十三种幺九，以及全部拆解取最高合法实际得点，沿用四麻第3／5节。每个已声明杠占一面子；拔北既不占面子，也不能代替手牌中的北。三麻输入必须拒绝二至八万，不能由通用34牌种分析器虚构这些等待。

通用役表沿用四麻：立直／双立直、一发、门清自摸、断幺、平和、一杯口／两杯口、各役牌、抢杠、岭上、海底／河底；七对子、对对和、三暗刻、三杠子、三色同刻、一气、混全／纯全、混老头、小三元、混一色／清一色；天和、地和、国士、四暗刻、大三元、小四喜／大四喜、字一色、绿一色、清老头、四杠子、九莲及对应特殊双倍。普通役门清限定、食下与排他按原表，**抢北不是抢杠役**，拔北补牌可以有岭上。

- 三色同顺因万子无顺子而不可能；不添加三麻替代役，也不把“无吃”误解为手内不能组成筒索顺子。三色同刻仍可由111万／筒／索或999万／筒／索成立。
- 国士所需十三幺九全部仍在牌池内；拔走北之后必须在实际手牌中重新具备国士需要的北，拔北区不参与牌形。七对子／国士不能包含已声明杠，但合法拔北不等于声明杠。
- 北为客风，北雀头不获自／场风2符；合法场风／自风连风雀头仍为4符。字牌北刻仍按幺九刻计算符，也可参与对对和、三暗刻、四喜等其他役。
- 普通计符沿用20副底、门清荣和＋10、自摸＋2、刻杠／役牌雀头／边嵌单骑、十位进位；平和自摸20、七对子25、副露无符荣和最低30等例外保留。拔北区不另外加符。
- 不切上满贯；累计13番以上单倍役满封顶；国士十三面、四暗刻单骑、纯正九莲、大四喜双倍及真实役满复合拟沿用同一雀魂预设。官方公开役配置已核对四种倍数；不为三麻发明额外役满。
- 形式听牌仍忽略无役、振听和外部待牌见尽；本人持牌／声明组／已拔北已经占满同种四枚时，不能再求第五枚。例如本人已拔3北、手内1北的北单骑不算形式听牌。此处把本人拔北计入自持副本约束是C组拟定沿用边界。
