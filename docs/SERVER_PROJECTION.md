# 服务端快照转换职责

日期：2026-10-20，开发版`0.0.19-dev`。从已验证`0.0.18-dev`／`945e518`继续，落实[代码审计](CODE_AUDIT.md)中的服务端纯快照提取。

## 职责边界

新增包内`GameSnapshotProjector`，接收规则核心已按接收者过滤的不可变View，以及由服务端确定的版本、暂停、提示、在场和恢复确认信息，转换为`GameSnapshot`。三麻／四麻各保留显式入口，统一杠及响应选项排序；三麻拔北字段继续显式处理。

提取范围包括单局座位／规则／合法动作、整场结果、番符／支付摘要，以及无真实响应时的临时等待显示转换。新的`Context`复制在场／确认集合，调用者后续修改原集合不会改变已创建的转换输入。

`LobbyService`继续拥有认证与视图令牌、核心动作、实际在场判断、暂停／恢复、响应窗口、等待计时、保存及里宝公开决定。新类不读取世界、不查询玩家、不接触隐藏牌墙、不调用规则动作，也不判断某身份有无权限。只有服务端确认可公开的里宝列表才进入转换。

本轮公用及陌生身份的`GameSnapshot`不含私手与私有合法动作；显式观看者的全手牌继续由原`TableScene`授权流程提供。未改变离椅参与者身份、观战规则、按钮、操作时序、协议或存档格式。没有新增缓存、第三方依赖，也没有合并两套规则状态机。
