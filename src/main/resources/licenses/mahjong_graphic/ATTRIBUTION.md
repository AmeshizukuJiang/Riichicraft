# Mahjong tile face artwork

Riichicraft uses a selected subset of **mahjong_graphic** by **lietxia**:
https://github.com/lietxia/mahjong_graphic

The upstream project distributes this artwork under the M+ font license.
The original license text is included in this directory as LICENSE.
Its README credits some glyphs to **I.Mahjong** by **內木一郎**:
https://github.com/SyaoranHinata/I.Mahjong
(in turn derived from Gutenberg Labo's GL-MahjongTile).

Riichicraft modifications: resize the supplied transparent PNG artwork, composite
onto a white face, generate an unmarked white dragon, and add an original ivory
body with a solid deep-green back and native 3D geometry. Source PNG/SVG pairs, original upstream
README, SHA-256 manifest and reproducible generators are kept in the repository.
No font file is bundled or installed. No connection with Mahjong Soul is claimed.
